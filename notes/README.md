# notes/

Scratch space — ad-hoc analysis, meeting notes, exploratory notebooks.
**Nothing here is committed in results;** load-bearing analysis should be
productionized into `oamv_hfmd/` or `scripts/`.

## Layout

- `analysis/` — Jupyter notebooks for one-off experiments and plots.
- `meetings/` — weekly progress notes (dated, e.g. `2026-05-22.md`).
